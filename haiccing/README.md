# haiccing (folder)

The projects of the `haiccing` organisation, each at `haiccing/<repo>`:
HAICC projects deployed with `haicc-deployment` and `haicc-reconcile`
(`pear-full-square/`). Today the demo projects, each sharing its name with
the Splectral component it runs (`splectral/<repo>`). How to run them:
`demos.md`.
