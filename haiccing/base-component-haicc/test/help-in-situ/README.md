# test/help-in-situ/

The generic help test where the package is deployed: its help as a running mrepo extracted it.

Run in a running mrepo with `runtime run`, which names the mrepo and the
package; skipped without them.

Its code is in the module the package carries, at
`modules/pear-full-square/mrepo-base-help/validate/help-in-situ.test.js`; `run.js` here runs
it. A generic test: the same folder in every package.
