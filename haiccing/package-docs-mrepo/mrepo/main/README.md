# /main

The mrepo's data: what it is for. Atomic: written by the runtime, one
commit at a time, only through a request's execution.

A section of `main` can have protocols of its own (`/protocols`).

An mrepo linked at a position has nothing here: it is a shortcut, in
`/xpath`. On disk, the `main/` folder is a shadow of this layer's
structure, where a linked mrepo's folder sits at its position.
