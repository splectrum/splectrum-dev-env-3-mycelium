# test/code/

The generic code test: the package's code checked against the code rules.

Each module of ours the package carries, and the package's own entry
points: a method folder with its `index.js` and README, imports that stay
in their module, no reference to a development repository.

Its code is in the module the package carries, at
`modules/pear-full-square/pkgm-base-check/validate/code.test.js`; `run.js` here runs
it. A generic test: the same folder in every package.
