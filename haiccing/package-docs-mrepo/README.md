# package-docs-mrepo

The mrepo structure, documented.

| | |
|---|---|
| [mrepo/](mrepo/) | the mrepo, documented in place: a folder a layer, its README |
| [modules/](modules/) | its dependencies, assembled: the help module its tests use |
| [test/](test/) | its tests: the generic ones, a folder each |
| [test-reports/](test-reports/) | the report of its last pre-release |

Later, beside it: `example/` (examples, with actual configs), tests that
check a repository complies.

Written from [splectrum/splectrum-dev-env-3-mycelium](https://github.com/splectrum/splectrum-dev-env-3-mycelium).
