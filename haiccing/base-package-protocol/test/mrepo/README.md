# test/mrepo/

The generic mrepo test: the integrity of the package's mrepo side.

Its `mrepo/` structure and hooks, its `protocol.js` with a function for
every action configured, and what it carries against its record.

Its code is in the module the package carries, at
`modules/pear-full-square/pkgm-base-check/validate/mrepo.test.js`; `run.js` here runs
it. A generic test: the same folder in every package.
