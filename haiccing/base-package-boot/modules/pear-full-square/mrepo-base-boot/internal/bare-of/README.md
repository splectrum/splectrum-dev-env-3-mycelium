# bare-of

Names the Bare a work folder's mrepos run on.

The one recorded in `<work>/bare.json`, else the pinned one at
`<work>/bare/bin/bare`.

## Signature

`bareOf(work)`

## Returns

The Bare's path.

## Also exported

`placed(work)`, the pinned Bare's path, and `recordOf(work)`, the record,
or null.
